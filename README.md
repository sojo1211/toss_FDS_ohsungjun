### 1️⃣ 온보딩 6대 Risk Factor 정밀 검수

가맹점 입점(Onboarding) 시 제출된 6대 리스크 팩터와 실제 웹사이트 운영 데이터 간의 **Discrepancy(불일치) 교차 검증**을 수행합니다.

| 검수 항목 | 주요 내용 |
|-----------|-----------|
| 배송 종류 | 국내 / 해외 여부 확인 |
| 배송·서비스 소요 시간 | 실제 배송 소요일 vs. 등록 정보 갭 검출 |
| 최고 객단가 | 실제 판매가 vs. 신고 객단가 불일치 감지 |
| 판매 형태 | 중개 / 다단계 / 사전예약 등 형태 검증 |
| 실물 / 비실물 구분 | 상품 유형별 리스크 팩터 분류 |
| 취소·환불 규정 | 약관 내 환불 조건과 실제 정책 비교 |
